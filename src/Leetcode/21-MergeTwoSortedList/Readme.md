# Merge Two Sorted Lists

## Descripción del problema

Dadas dos listas enlazadas ordenadas en orden ascendente, fusiona ambas listas en una sola lista enlazada ordenada y retorna su cabeza. La lista resultante debe estar formada enlazando los nodos de las listas originales, no creando nuevos nodos.

### Ejemplo

**Input:**
- Lista 1: 1 → 2 → 4
- Lista 2: 1 → 3 → 4

**Output:**
- 1 → 1 → 2 → 3 → 4 → 4

### Restricciones
- Las listas pueden estar vacías (null).
- Los valores de los nodos están en orden ascendente.
- Se debe mantener el orden y reutilizar los nodos existentes.
