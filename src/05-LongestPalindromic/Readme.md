# Longest Palindromic Substring

Dado un string `s`, encuentra y retorna el substring palindrómico más largo dentro de `s`.

Un palíndromo es una secuencia que se lee igual de izquierda a derecha que de derecha a izquierda.

## Ejemplos

**Ejemplo 1:**
- Entrada: `s = "babad"`
- Salida: `"bab"` ("aba" también es válido)

**Ejemplo 2:**
- Entrada: `s = "cbbd"`
- Salida: `"bb"`

## Restricciones
- 1 <= s.length <= 1000
- `s` consiste solo de dígitos y letras inglesas.
